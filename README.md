# SGRE-German-Patch
English
1. Replace the files in SGRE\wind3d11data\.
2. Go to Settings -> Language -> select "繁体中文" -> Start. 

There are still some bugs, but it's fully playable. (Images, videos, and the @Channel are not translated yet as they require a lot of effort.)

Deutsch
1. Ersetze die Dateien im Ordner SGRE\wind3d11data\.
2. Gehe zu Optionen (oder Einstellungen) -> Sprache -> wähle „繁体中文“ -> Spiel starten. 

Es gibt noch einige Bugs, aber der Patch ist spielbar. (Bilder, Videos und der @Channel wurden noch nicht übersetzt, da dies sehr aufwendig ist.)
